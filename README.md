# HFH Internal CRM Bot

Внутренний Telegram-бот для диспетчеров, курьеров и сотрудников прачечной. Клиентского интерфейса нет. Бот использует aiogram 3, асинхронный SQLAlchemy и SQLite.

## Запуск

Требуется Python 3.10 или новее и токен Telegram-бота от BotFather.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Укажите `BOT_TOKEN`, Telegram numeric IDs администраторов в `ADMIN_IDS` (через запятую) и контакт в `GEOCODER_USER_AGENT`. Затем запустите:

```bash
python main.py
```

SQLite-файл создаётся автоматически. Для постоянного хранения при контейнерном запуске подключите volume к файлу, указанному в `DATABASE_URL`. Запускайте один экземпляр бота: FSM хранится в памяти, а встроенное ограничение публичного Nominatim рассчитано на один процесс.

## Доступ и роли

Сотрудник отправляет `/start`; до одобрения ему недоступны рабочие обработчики. Все Telegram IDs из `ADMIN_IDS` имеют права Super Admin. Кнопки админ-панели: список сотрудников с изменением роли/отключением, ожидающие заявки с назначением роли, статистика заказов и сотрудников, а также последние 20 заказов с возможностью отмены. Панель открывается командой `/admin`. Новые запросы на доступ отправляются каждому настроенному администратору.

## Рабочие процессы

- **Диспетчер:** кнопка «Новая заявка» или `/new_order`, затем имя и улица с номером дома. Проверьте результат кнопкой поиска в 2ГИС и подтвердите адрес, выберите многоквартирный или частный дом; для квартиры укажите подъезд, этаж и квартиру (либо пропустите уточнения). Затем выберите день забора: «Сегодня», «Завтра» или дата `ДД.ММ.ГГГГ`; в заказ записывается конкретная дата по времени Бишкека. `/orders` показывает последние 30 заказов. Из карточки можно выбрать и изменить отдельное поле или отменить заказ; изменение адреса проходит такую же проверку. `/cancel` прерывает ввод, `/help` показывает подсказку.
- **Курьер:** «Начать смену», затем отправка геопозиции; список задач сортируется по расстоянию. Включите отправку live location в Telegram, чтобы обновления позиции поступали во время движения. Доступны отдельные pickup- и delivery-переходы; заказ закрепляется за курьером при начале соответствующего этапа.
- **Прачечная:** `/order 15` или «Найти заказ», вводит замеры свободным текстом (например, `Ковёр 3x4 м; шторы 4 шт.`), затем помечает обработанный заказ готовым. Он сразу попадает в очередь доставки. `/cancel` прерывает ввод, `/help` показывает подсказку.

Все роли могут отправить `/help`. Неизвестные сообщения и устаревшие inline-кнопки получают понятный ответ.

## Геокодирование и эксплуатация

Адрес диспетчер вручную сверяет через ссылку поиска 2ГИС; координаты улицы и дома геокодируются через Nominatim-совместимый endpoint в Bishkek, Kyrgyzstan. Встроено ограничение не чаще одного запроса в секунду. Сервис может не найти адрес, отказать или быть недоступен; создание заказа при этом продолжается, а заказ без координат отображается в конце списка. Ссылка 2GIS для курьера показывается только для геокодированного заказа. Для production следует настроить собственный/коммерческий геокодер с подходящими SLA и проверить условия использования выбранного endpoint; публичный Nominatim не является production SLA-сервисом.

Времена создания записываются в UTC и отображаются в часовом поясе Asia/Bishkek. Защитите `.env` и файл SQLite резервными копиями. FSM-состояния не переживают перезапуск; для многопроцессного/высокодоступного запуска замените `MemoryStorage` на Redis и согласуйте геокодирование между экземплярами. Учётные записи сотрудников хранят Telegram ID и рабочие данные заказов; ограничьте доступ к хосту и резервным копиям.
